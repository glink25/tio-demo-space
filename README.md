# Tio 示例空间

包含富文本、记账、训练日记和热量手账，全部使用演示数据。

## 快速开始

1. [Fork 本仓库](https://github.com/glink25/tio-demo-space/fork)，保留 `tio-` 名称前缀。
2. 打开 [Tio](https://tio.linkai.work/)，连接 GitHub，并允许访问 Fork 后的仓库。
3. 打开自动发现的「Tio · 创作实验室」空间，即可查看和编辑示例。

首次使用记账、训练日记或热量手账时，请在 App Slice 权限设置中授予对应数据库的**读写权限**，才能新增记录。修改会同步到你自己的 Fork。

## 本地查看

下载并解压本仓库，在 Tio 中通过本地文件夹连接打开解压后的仓库根目录。

了解更多：[Tio 项目](https://github.com/glink25/tio)。
